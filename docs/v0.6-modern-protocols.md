# ProxyFlow V0.6 Modern Protocols

> Historical document for the V0.6 modern-protocol milestone.

V0.6 扩展现有 `Graph → Universal IR → Semantic Validation → Independent Target Compilers` 架构，不引入第二套 TLS 模型，也不让一个目标编译器借用另一个目标的产物。

> Post-V0.6 development note：当时的后续开发分支沿用同一架构增加 AnyTLS 与新版 Filter；这是向后兼容 enhancement，不改写已经发布的 V0.6 scope，也不提升 Project Schema V2。

## 统一语义

- `ProxyTlsIR` 统一保存 SNI、disable-SNI、证书校验、ALPN、客户端指纹与 Reality public key / short ID。
- Hysteria2 port hopping 使用 `single | range` 判别联合类型；IR 不保存 Mihomo 的 `443-445` 或 sing-box 的 `443:445` 字符串。
- Hysteria2 hop interval 使用 `fixed | range` 判别联合类型；不会把 `15-30` 截断为 `15`。
- HTTP transport 必须显式携带 `http | h2` variant；HTTP proxy protocol 仍是独立的 endpoint 类型。
- VLESS `security` 只接受 `none | tls | reality`，`flow` 只接受 `xtls-rprx-vision`；未知值使用稳定诊断标为 Partial 并从可用集合排除。
- Reality 缺少 public key 或显式 SNI 时为 Partial。完整 Reality 可独立 lowering 到 Mihomo `reality-opts` 和 sing-box `tls.reality`。
- 解析诊断与兼容状态分离：普通未知 metadata 或相同值重复只产生 warning。SNI、security、flow、Reality key/short ID、transport、Host/path 与 early-data 等连接关键参数若出现冲突值，则标为 Partial 并失败闭合。
- `validateProxyEndpointSemantics()` 是 core 层、target-neutral 的纯函数；Share Parser、Clash Parser 与 `validateIR()` 共用同一组跨字段不变量。Direct/manual IR 无法借由绕过 Parser 生成禁用 TLS 的 Reality/Vision/Trojan/Hysteria2/TUIC。
- `security=none` 与 Reality/Vision、TLS disabled 与 TLS-only fields、非法 VMess TLS/aid/TCP header，以及显式非法 Hysteria2 bandwidth 都失败闭合。`encryption:none`、`flow:none` 与 `disable-sni:false` 等规范 no-op 不会单独导致 Partial。

## Transport 矩阵

| IR transport | Mihomo | sing-box 1.13.14 |
| --- | --- | --- |
| TCP | `network: tcp` | 无 transport 对象 |
| WebSocket | `network: ws` + `ws-opts` | `transport.type: ws` |
| HTTP variant，无 TLS | `http-opts` | `transport.type: http`（HTTP/1.1） |
| HTTP variant，启用 TLS | `http-opts` | Unsupported；`SINGBOX_TRANSPORT_HTTP_TLS_VARIANT_UNSUPPORTED` |
| H2 variant，启用 TLS | `h2-opts` | `transport.type: http` + TLS（HTTP/2） |
| H2 variant，无 TLS | `h2-opts` | Unsupported；`SINGBOX_TRANSPORT_H2_REQUIRES_TLS` |
| gRPC | `grpc-opts` | `transport.type: grpc` |
| HTTPUpgrade | WS transport + `v2ray-http-upgrade` | `transport.type: httpupgrade` |
| XHTTP | `network: xhttp` + `xhttp-opts` | 不支持，`SINGBOX_TRANSPORT_XHTTP_UNSUPPORTED` 失败闭合 |

WS path、Host、early data 和 header name 会保留。gRPC service name 会保留；无法跨目标可靠表达的 authority 会成为 Partial，而不是静默丢失。

非法 WS early-data 不会被静默删除；Parser 返回 `PROXY_WS_EARLY_DATA_INVALID` 并将节点标为 Partial。Clash/Mihomo 的 HTTPUpgrade 读取真实结构 `network: ws` + `ws-opts.v2ray-http-upgrade: true`，再由两个 Target Compiler 独立 lowering。

## Hysteria2 与 TUIC v5

Hysteria2 IR 保存认证密码、TLS、SNI、insecure、ALPN、Salamander obfs、上下行带宽与结构化端口跳跃字段。官方 authority 多端口语法（例如 `host:443,5000-6000`）为 Supported；未写端口时使用 443。TUIC v5 IR 保存 UUID、密码、TLS、disable-SNI、拥塞控制和 UDP relay mode。Node Preview 只显示协议、安全与 transport 摘要，不显示密码、完整 UUID、Reality key 或完整订阅 URL。

显式 bandwidth 必须完整匹配受支持格式且为正数；不存在时才表示未设置。`15garbage` 不会被截断或退化为“未设置”，而是返回 `PROXY_HYSTERIA2_BANDWIDTH_INVALID` 并标记 Partial。

| Feature | Parser / IR | Mihomo | sing-box 1.13.14 |
| --- | --- | --- | --- |
| Hysteria2 single/range ports | Supported | `443,5000-6000` | `['443', '5000:6000']` |
| Fixed hop interval | Supported | Supported | Supported |
| Random hop interval | Supported | Supported (`15-30`) | Unsupported；`SINGBOX_HYSTERIA2_RANDOM_HOP_INTERVAL_UNSUPPORTED` |
| Hysteria2 `pinSHA256` / ECH | Partial | Fail closed | Fail closed |
| TUIC allow-insecure / disable-SNI | Supported | Supported | Supported |
| Clash TLS certificate fingerprint | Partial | Fail closed | Fail closed |
| Hysteria2 / TUIC client fingerprint | IR 可表达；target-dependent | Unsupported | Unsupported；QUIC custom TLS 仅支持 ECH |
| Hysteria2 / TUIC as sing-box chain exit | Supported | Target-specific chain rules | Supported through Dial Fields `detour` |

## Post-V0.6 Filter 与 AnyTLS

Filter 新 model 使用 `keyword | region | regex` 判别 mode 和 `include | exclude` operation。Keyword trim 后不区分大小写；Region 保存稳定 code 并通过 flag / token / localized alias 做确定性 metadata inference；Regex 分开保存 pattern 与 ignore-case flag。非法 Regex 返回 `FILTER_INVALID_REGEX` 并阻止 transform。旧版 Filter 字段继续读取，因此 Project Schema 保持 V2。

AnyTLS IR 保存 target-neutral password、required TLS、serverName、insecure、ALPN、client fingerprint、UDP intent 与 idle-session semantics。分享 URI 与 Clash/Mihomo YAML 都经过同一 Semantic Firewall。

| AnyTLS feature | Parser / IR | Mihomo | sing-box 1.13.14 |
|---|---|---|---|
| Password / server / port（default 443） | Supported | Supported | Supported |
| SNI / insecure / ALPN / client fingerprint | Supported | Supported | Supported through TLS / uTLS |
| Idle check / timeout / minimum idle sessions | Supported | Supported | Supported |
| Chain exit | Target-neutral strategy intent | Target chain lowering | Supported through Dial Fields `detour` |
| Explicit UDP disable | Supported intent | Supported | Unsupported；stable compatibility error |
| Reality / unknown connection-critical params | Partial or IR error | Fail closed | Fail closed |
| `client_metadata` | Partial | Unsupported | Unsupported on 1.13.14（introduced in 1.13.16） |

## 基线与验证

- sing-box 编译基线固定为 `1.13.14`。
- Mihomo 与 sing-box compiler 都从同一份 IR 独立生成配置，并使用稳定目标错误码。
- fixtures 覆盖 Reality、Vision、现代 transport、Hysteria2、TUIC、混合与畸形输入。
- 若本机存在 `mihomo` 或 `sing-box`，可进一步运行真实二进制配置检查；缺少二进制时测试只验证类型、序列化 roundtrip、语义断言与确定性。
